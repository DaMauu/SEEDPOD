### การรายงานช่องโหว่

โปรด**อย่า**รายงานปัญหาความปลอดภัยผ่าน Issue สาธารณะ ให้ใช้ช่องทางส่วนตัวของ repository:

1. เปิดแท็บ [Security](../../security/advisories) แล้วคลิก "Report a vulnerability";
2. หรือติดต่อผู้ดูแลโดยตรง พร้อมระบุขั้นตอนการทำซ้ำและผลกระทบ

เราจะพยายามตอบกลับภายใน 7 วัน และจะตกลงเรื่องการแก้ไขและกำหนดเวลาเปิดเผยกับคุณ

### สิ่งที่ควรรายงาน

userscript ของ SEEDPOD ทำงานบนหน้าเว็บ tracker ส่วนตัวที่คุณล็อกอินอยู่ สามารถอ่านเนื้อหาหน้าและส่งคำขอแทนคุณได้ ทั้งหมดต่อไปนี้นับเป็นปัญหาความปลอดภัย:

- ข้อมูลรับรอง (cookie, passkey, คีย์ tracker, รหัสผ่านบัญชี) ถูกส่งไปยังปลายทางของบุคคลที่สาม
- คำขอออกภายนอกที่ไม่มีในเอกสาร (ไปยังโดเมนอื่นนอกเหนือจากเซิร์ฟเวอร์รูปภาพ CDN หรือบริการที่เอกสารระบุ)
- เส้นทาง XSS ที่ฉีดเนื้อหาซึ่งผู้โจมตีควบคุมเข้าสู่แผงควบคุมหรือกล่องโต้ตอบ
- การฉีดสิทธิ์หรือพารามิเตอร์ในขั้นตอนตรวจซ้ำข้ามไซต์ การกรอกฟอร์มอัปโหลด หรือการส่งไปยัง downloader
- สไตล์ชีตที่โหลดทรัพยากรที่ไม่น่าเชื่อถือผ่าน `@import` ภายนอก

### อยู่นอกขอบเขต

- ช่องโหว่ของตัว tracker เอง (โปรดรายงานไปยังไซต์ที่เกี่ยวข้อง)
- กฎของไซต์ เนื้อหา torrent หรือการระงับบัญชี
- ปัญหาที่ต้องเข้าถึงไฟล์ในเครื่องหรือบริบทของส่วนขยายเบราว์เซอร์ของคุณก่อน

### เมื่อส่ง Issue หรือ PR

ก่อนโพสต์ log หรือภาพหน้าจอ ให้ลบ: cookie, passkey, คีย์ tracker, ที่อยู่และรหัสผ่านของ downloader และชื่อผู้ใช้บนไซต์ เก็บ stack trace ไว้ อย่าวาง header ของคำขอทั้งชุด
