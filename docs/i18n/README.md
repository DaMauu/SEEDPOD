## 许可证说明

LICENSE 是 GNU GPL v3 的英文原文，**具有法律效力的只有这一份，不翻译、不改写**。上表「许可说明」一列是各语言的授权说明页，讲 GPL 允许什么、要求什么，并指向 GNU 官方的译本索引供参考；与英文原文冲突时以英文原文为准。

The `LICENSE` file is the English original of GNU GPL v3 and is the only legally binding text. The localized pages explain what the license allows and requires, and point to GNU's official translations index for reading; the English original prevails in case of conflict.

## 校对与更新

- 简体中文与英文是唯一权威版本，其余语言改自这两份。
- 修改根目录文档后，本目录下的译本需要同步；发现译文偏差请直接提 PR，并在描述里注明对应语言与段落。
- 语言代码遵循 BCP 47：`zh-TW` 繁体中文、`ja` 日语、`ko` 韩语、`ru` 俄语、`de` 德语、`fr` 法语、`es` 西班牙语、`pt` 葡萄牙语、`it` 意大利语、`nl` 荷兰语、`pl` 波兰语、`tr` 土耳其语、`vi` 越南语、`th` 泰语、`id` 印尼语、`ar` 阿拉伯语。
