### 脆弱性の報告

セキュリティ上の問題を公開 Issue で報告しないでください。リポジトリの非公開チャネルをご利用ください：

1. [Security](../../security/advisories) タブを開き、「Report a vulnerability」をクリックします；
2. または、再現手順と影響範囲を添えてメンテナに直接連絡してください。

7 日以内に初回返信を行うよう努め、確認後に修正と公開の時期を協議します。

### 報告すべき内容

SEEDPOD のユーザースクリプトはログイン済みのプライベートトラッカーのページ上で動作し、ページの内容を読み取り、あなたの代わりにリクエストを送信できます。以下はすべてセキュリティ上の問題とみなします：

- cookie、passkey、トラッカーの鍵、アカウントのパスワードが第三者アドレスへ送信される
- 文書化されていない外部リクエスト（画像ホスト、CDN、または文書に記載されたサービス以外のドメインへの送信）
- 攻撃者が制御する内容をパネルやダイアログに注入できる XSS 経路
- サイト間の重複チェック、アップロードフォームの記入、ダウンローダーへのプッシュにおける権限昇格またはパラメータインジェクション
- 外部 `@import` による信頼できないリソースの読み込み

### 対象外

- トラッカー自体の脆弱性（該当サイトへ報告してください）
- サイトのルール、トレントの内容、アカウントの停止
- あなたのローカルファイルやブラウザ拡張機能のコンテキストへの事前アクセスを必要とする問題

### Issue や PR を出すとき

ログやスクリーンショットを投稿する前に、次を削除してください：cookie、passkey、トラッカーの鍵、ダウンローダーのアドレスとパスワード、サイトのユーザー名。スタックトレースは残してかまいませんが、リクエストヘッダーを丸ごと貼り付けないでください。
