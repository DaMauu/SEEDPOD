ขอบคุณที่สนใจปรับปรุง SEEDPOD อ่านหน้านี้สักรอบก่อนจะช่วยลดการถามตอบไปมาได้มาก

### ที่เก็บนี้คืออะไร

ส่วนเสริมแบบไฟล์เดียว: userscript ของ Tampermonkey และ stylesheet ภายนอก **ไม่ต้อง build ไม่มี dependency ไม่มี backend** — วางไฟล์เดียวก็ใช้งานได้ อย่านำ bundler, dependency ของ npm หรือขั้นตอนคอมไพล์เข้ามาใน PR

### โครงสร้างไดเรกทอรี

| พาธ | เนื้อหา |
|---|---|
| `scripts/bluray/legacy/` | เวอร์ชันที่เผยแพร่ของแผง bluray หนึ่งไฟล์ต่อหนึ่งเวอร์ชัน |
| `scripts/bluray/docs/` | เริ่มต้นอย่างรวดเร็ว คู่มือ สถาปัตยกรรม บันทึกการพัฒนา |
| `scripts/PTScripts/` | รวมเครื่องมือเสริมสำหรับ tracker ติดตาม upstream `DaMauu/Scripts` |
| `styles/r/` | สไตล์ธีมของ tracker |
| `pta/` | หน้ารวบรวมโน้ตสถาปัตยกรรม tracker ภายในเครื่อง |

### การกำหนดเวอร์ชัน

- **bluray**: ชื่อไฟล์ `pt-bluray-assistant-v0.0.0.N.user.js` สี่ส่วนเพิ่มขึ้นตามลำดับ **ห้ามเขียนทับหรือลบเวอร์ชันเก่าเด็ดขาด** — ให้เพิ่มไฟล์ใหม่แทน หัว `@version` ชื่อแผง และบรรทัด log ตอนฉีดสคริปต์ต้องตรงกันทั้งสามจุด
- **styles**: หนึ่งไฟล์ต่อหนึ่งสไตล์ เมื่อแก้ไขให้เพิ่มเลขเวอร์ชันและติด tag; tag เก่าจะคงอยู่ตลอดเพื่อให้ผู้ใช้ย้อนกลับได้
- **PTScripts**: ที่เก็บนี้รับประกันเพียงว่าไฟล์ยังออนไลน์อยู่ upstream `DaMauu/Scripts` คือแหล่งอ้างอิงที่แท้จริง ส่งการแก้ไขไปที่ upstream ก่อน แล้วจึงซิงก์กลับมา

### ก่อนส่งงาน

1. สคริปต์ติดตั้งใน Tampermonkey ได้และทำงานจริงบนไซต์เป้าหมาย ไม่ใช่ “น่าจะใช้ได้”
2. ระบุว่าตรวจสอบบน tracker ประเภทใด (NexusPHP / UNIT3D / Gazelle / f3nix) ถ้ามีชื่อไซต์ด้วยจะยิ่งดี
3. ลบ `console.log` ที่ใช้ดีบัก เส้นทางไฟล์ในเครื่อง และบัญชีทดสอบออก
4. อย่า commit ข้อมูล tracker ในเครื่อง: `data/site-defs/` และ `pta/data/site-arch.local.csv` อยู่ใน `.gitignore` แล้ว อย่าใช้ `git add -f` ฝืนเพิ่ม
5. **ห้าม commit** cookie, passkey, คีย์ tracker, API key หรือภาพหน้าจอที่มีข้อมูลส่วนบุคคลเด็ดขาด

### ข้อความ commit

อธิบายสั้น ๆ ว่าเปลี่ยนอะไรและกระทบโมดูลใด เช่น:

```
bluray: 修复 UNIT3D 站点填单时海报字段丢失
styles/r: 调深列表分隔线
```

ใช้ภาษาจีนหรืออังกฤษก็ได้ทั้งคู่

### Pull request

- หนึ่ง PR ทำเรื่องเดียว อย่าใส่การจัดรูปแบบที่ไม่เกี่ยวข้องปนเข้ามา
- อธิบาย: เหตุผล โมดูลที่ได้รับผลกระทบ วิธีตรวจสอบและผลลัพธ์ และไฟล์เวอร์ชันเก่าถูกแตะหรือไม่
- แนบภาพหน้าจอเมื่อแก้แผงหรือสไตล์ โดยปิดบัญชีและคีย์ก่อน

### Issue

แจ้งบั๊กและข้อเสนอแนะตามแม่แบบ สำหรับปัญหาความปลอดภัยอย่าเปิด Issue สาธารณะ — ดู [SECURITY.md](../../SECURITY.md)
