Спасибо, что хотите улучшить SEEDPOD. Сначала прочитайте эту страницу — это избавит от большей части переписки.

### Что представляет собой этот репозиторий

Однофайловые дополнения: пользовательские скрипты для Tampermonkey и внешние таблицы стилей. **Ни сборки, ни зависимостей, ни бэкенда** — положил один файл, и всё работает. Не добавляйте в PR сборщики, зависимости npm или шаги компиляции.

### Структура

| Путь | Содержимое |
|---|---|
| `scripts/bluray/legacy/` | Выпущенные версии панели bluray, один файл на версию |
| `scripts/bluray/docs/` | Быстрый старт, руководство, архитектура, заметки по разработке |
| `scripts/PTScripts/` | Набор утилит для трекеров, следует за апстримом `DaMauu/Scripts` |
| `styles/r/` | Стили тем для трекеров |
| `pta/` | Страница с заметками о локальной архитектуре трекеров |

### Правила версионирования

- **bluray**: имя файла `pt-bluray-assistant-v0.0.0.N.user.js`, четыре сегмента, по возрастанию. **Никогда не перезаписывать и не удалять старую версию** — вместо этого добавляйте новый файл. Заголовок `@version`, заголовок панели и строка в журнале внедрения должны совпадать.
- **styles**: один файл на стиль, при изменении поднимайте версию и ставьте тег; старые теги остаются навсегда, чтобы пользователи могли откатиться.
- **PTScripts**: репозиторий гарантирует только то, что файлы остаются доступными; источник истины — апстрим `DaMauu/Scripts`. Сначала отправляйте изменения в апстрим, затем синхронизируйте обратно.

### Перед отправкой

1. Скрипт устанавливается в Tampermonkey и действительно работает на целевом сайте — а не «должен работать».
2. Укажите, на каких типах трекеров вы проверяли (NexusPHP / UNIT3D / Gazelle / f3nix); названия сайтов помогут.
3. Удалите отладочные `console.log`, локальные пути и тестовые аккаунты.
4. Не коммитьте локальные данные трекеров: `pta/web/assets/sites-data.local.js` и `pta/data/site-arch.local.csv` находятся в `.gitignore` — никогда не добавляйте их через `git add -f`.
5. **Никогда не коммитьте** cookies, passkey, ключи трекеров, ключи API и скриншоты с личными данными.

### Сообщения коммитов

Короткое описание того, что изменилось и какой модуль затронут, например:

```
bluray: 修复 UNIT3D 站点填单时海报字段丢失
styles/r: 调深列表分隔线
```

Китайский или английский — оба подходят.

### Pull Request

- Один PR — одна задача; не смешивайте постороннее форматирование.
- Опишите: мотивацию, затронутые модули, как вы проверяли и результат, а также затрагиваются ли файлы старых версий.
- Для изменений панели или стилей приложите скриншоты, скрыв аккаунты и ключи.

### Issue

Об ошибках и пожеланиях пишите через шаблоны. По вопросам безопасности не открывайте публичный Issue — см. [SECURITY.md](../../SECURITY.md).
