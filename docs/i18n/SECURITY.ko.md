### 취약점 신고

보안 문제를 공개 Issue 로 신고하지 마세요. 저장소의 비공개 채널을 이용해 주세요:

1. [Security](../../security/advisories) 탭을 열고 "Report a vulnerability" 를 클릭합니다;
2. 또는 재현 단계와 영향 범위를 적어 관리자에게 직접 연락합니다.

7일 이내에 1차 답변을 드리며, 확인 후 수정과 공개 시점을 협의합니다.

### 신고해야 할 내용

SEEDPOD 의 사용자 스크립트는 로그인된 비공개 트래커 페이지에서 실행되며, 페이지 내용을 읽고 사용자를 대신해 요청을 보낼 수 있습니다. 다음은 모두 보안 문제로 봅니다:

- cookie, passkey, 트래커 키, 계정 비밀번호가 제3자 주소로 전송되는 경우
- 문서화되지 않은 외부 요청 (이미지 호스트, CDN 또는 문서에 설명된 서비스 외 도메인으로의 전송)
- 공격자가 제어하는 콘텐츠를 패널이나 대화 상자에 주입할 수 있는 XSS 경로
- 사이트 간 중복 검사, 업로드 양식 작성, 다운로더 푸시 단계의 권한 상승 또는 매개변수 주입
- 외부 `@import` 를 통해 신뢰할 수 없는 리소스를 불러오는 스타일시트

### 대상 범위 밖

- 트래커 자체의 취약점 (해당 사이트에 신고하세요)
- 사이트 규칙, 토렌트 콘텐츠, 계정 정지
- 로컬 파일이나 브라우저 확장 프로그램의 컨텍스트에 대한 사전 접근이 필요한 문제

### Issue 또는 PR 을 올릴 때

로그나 스크린샷을 게시하기 전에 다음을 삭제하세요: cookie, passkey, 트래커 키, 다운로더 주소와 비밀번호, 사이트 사용자 이름. 스택 트레이스는 남겨 두되 요청 헤더를 통째로 붙여 넣지 마세요.
