### 回報漏洞

請**不要**透過公開 Issue 回報安全問題。請使用儲存庫的私密管道：

1. 開啟 [Security](../../security/advisories) 分頁，點選「Report a vulnerability」；
2. 或直接聯絡維護者，說明重現步驟與影響範圍。

我們會在 7 天內首次回覆，確認後再協商修正與公開時間。

### 需要回報什麼

SEEDPOD 的使用者腳本執行在已登入的私有站點頁面上，能讀取頁面內容，並代你發出請求。以下都算安全問題：

- 腳本將 cookie、passkey、Tracker 金鑰、站點帳號密碼傳送到第三方位址
- 未經說明的對外請求（送往圖床、CDN 或文件所述服務以外網域的請求）
- 可將攻擊者控制的內容注入面板或對話框的 XSS 路徑
- 跨站查重、填寫表單、推送下載器環節的越權或參數注入
- 樣式表透過外部 `@import` 載入不受信任的資源

### 不在範圍內

- 站點本身的漏洞（請回報給對應站點）
- 站點規則、種子內容或帳號停權
- 需要先取得你本機檔案或瀏覽器擴充功能權限才能利用的問題

### 提交 Issue 或 PR 時

張貼日誌與截圖前，請移除：cookie、passkey、Tracker 金鑰、下載器位址與密碼、站點使用者名稱。保留堆疊追蹤即可，不要整段貼上請求標頭。
