## 我們的承諾

我們作為成員、貢獻者與領導者，承諾讓參與本社群的體驗對所有人都不帶騷擾，無論年齡、體型、可見或不可見的障礙、族裔、性特徵、性別認同與表達、經驗程度、教育、社會經濟地位、國籍、外貌、種族、宗教或性認同與性傾向。

我們承諾以有助於營造開放、友善、多元、包容且健康社群的方式行動與互動。

## 我們的標準

有助於營造正向環境的行為範例：

- 對他人展現同理心與善意
- 尊重不同的意見、觀點與經驗
- 給予建設性回饋，並坦然接受建設性回饋
- 承擔責任，向因我們的錯誤而受影響的人道歉，並從中學習
- 不僅關注我們個人的最佳利益，也關注整個社群的最佳利益

不可接受的行為範例：

- 使用性化的語言或圖像，以及任何形式的性關注或性邀約
- 釣魚式引戰、侮辱或貶抑的評論，以及人身或政治攻擊
- 公開或私下的騷擾
- 未經他人明確許可，公布其私人資訊，例如實際地址、電子郵件地址或站點帳號
- 其他在專業場域中可合理認為不當的行為

## 適用範圍

本行為守則適用於所有專案空間，也適用於個人在公開場合正式代表專案時。

## 執行

辱罵、騷擾或其他不可接受的行為，可透過本儲存庫的 Issues 或私下向維護者舉報。所有申訴都會被及時且公平地審查與調查。

維護者有義務尊重任何事件舉報人的隱私與安全。執行方式依 Contributor Covenant v2.1 的執行指南，從更正與警告，逐步升級至暫時或永久封禁。
