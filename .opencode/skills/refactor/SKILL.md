name: Safe Refactor

---

## 何时用
用户说「拆一下这个文件」「抽个模块」「改个名」「减重」，而不是改行为。

## 步骤
1. 记录起始 commit 和拆前行数；先跑对应检查作为基线。
2. 只做结构改动：保持导出名、require 路径、接口字段、错误码、规则 key。
3. 一次一个模块；旧入口保留 re-export，或一次改完所有引用并跑全量。
4. UI 改动跑 1280/390 快照，通过后才更新 UI 基线。
5. 跑对应检查 + 全量；报告拆前/拆后行数；单独提交。

## 输出
- 拆前/拆后行数
- 新模块与旧入口
- 检查/快照结果
- 行为未变的证据
