## 说明

- 安装地址就是本库的 raw 链接，格式 `/raw/main/scripts/PTScripts/<文件名>`，文件名里的空格要写成 `%20`。
- `PT_FSMHide` 没有 `.user.js` 后缀，Tampermonkey 可能不认，装的时候手动改名为 `PT_FSMHide.user.js`。
- 新增脚本：把文件丢进本目录，再在表格里补一行；表格按 `@name` 排序。
