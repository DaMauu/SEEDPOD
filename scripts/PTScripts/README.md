## 说明

- 安装地址为本库 raw 链接，格式 `/raw/main/scripts/PTScripts/<文件名>`，文件名含空格时写作 `%20`。
- `PT_FSMHide.js` 不是标准 `.user.js` 后缀，Tampermonkey 装不上时改名为 `PT_FSMHide.user.js`。
- 新增脚本：文件丢进本目录，再在表格里补一行，表格按 `@name` 排序。
