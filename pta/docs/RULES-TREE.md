# 流程页规则树（类目 / 手风琴 / 里面的每一条）

由 `pta/web/assets/data.js` 直接生成：`node pta/scripts/gen-rules-tree.js`。行末的 [类型] 是控件形态，后面是选项或默认值。

## 抓取（fetch，4 个手风琴）

├─ 搜索预设（4 行）
│  ├─ 类型 [custom] 选项：电影 / 剧集 / 综艺 / 动漫 / 纪录片 / 音乐 / 体育 / 演唱会 / MV / 有声书 / 电子书 / 软件 / 游戏 / 其他 说明：对应站点搜索的类别，决定列表里会出现什么
│  ├─ 媒介 [custom] 选项：原盘(Full Disc) / UHD 原盘 / 3D 原盘 / Remux / Encode / Blu-ray / HDDVD / DVD / HDTV / WEB-DL / WEBRip / TVRip / VHS / 其他 说明：锁到站点的 medium / type 字段
│  ├─ 分辨率 [custom] 选项：480p / 576p / 720p / 1080i / 1080p / 2160p / 4320p/8K
│  └─ 优惠 [custom] 选项：免费 / 2x / 2x 免费 / 50% / 2x 50% / 30% / 普通 / 置顶精选 说明：按站点优惠状态筛，BHD 这类站点没有免费选项时会自动跳过

├─ 抓取标记（9 行）
│  ├─ 非电影跳过 [switch] 开关 说明：剧集、综艺、动漫、音乐都算非电影
│  ├─ 非纯原盘跳过 [switch] 开关 说明：标题里没有原盘特征、或者带 Remux/编码的，一律跳
│  ├─ DIY 跳过 [switch] 开关 说明：只打标记，是否跳过交给第二步筛选
│  ├─ 禁转跳过 [switch] 开关 说明：只打标记，是否跳过交给第二步筛选
│  ├─ 独占跳过 [switch] 开关 说明：只打标记，是否跳过交给第二步筛选
│  ├─ 限转未满 7 天跳过 [switch] 开关 说明：满 7 天的限转放行，并在行上标出来
│  ├─ 仅 DIY 时标可发 [switch] 开关 说明：B 站只有 DIY 版时，可以发纯原盘，标「复核」
│  ├─ 排除关键词 [text] 默认：DVDRip, 枪版, TS 说明：标题命中直接跳
│  └─ 白名单关键词 [text] 提示：只收含这些词的（留空不限） 说明：只打标记，是否跳过交给第二步筛选

├─ 拉取（10 行）
│  ├─ 请求间隔 [fixed] 默认：跟随设置 说明：只可在「设置 › 抓取节奏」里调，区间 8–120 秒
│  ├─ 并发 [fixed] 默认：1 说明：固定单线程，程序写死
│  ├─ 每轮最多翻页 [num] 提示：1–20
│  ├─ 抓取方式 [select] 选项：增量（只抓新页） / 全量（扫全部页） / 增量 + 定期全量
│  ├─ 断点续抓 [switch] 开关 说明：记到第几页、哪些种子已处理，停了下轮接着来
│  ├─ 抓详情页 [switch] 开关 说明：BDInfo、截图、简介都要进详情页
│  ├─ 失败重试 [fixed] 默认：3 次 · 退避 30 秒起
│  ├─ 连续失败自动停 [fixed] 默认：5 次
│  ├─ 单站每日最多抓 [fixed] 默认：跟随设置 说明：程序按站规再压一次，最多到站规的 1/3
│  └─ 全站每日最多抓 [fixed] 默认：跟随设置

└─ 站点分类映射（2 行）
   ├─ 站点分类 [button] 默认：配置映射 说明：把每个站自己的分类（如 Movies/Blu-ray）对到库内类型
   └─ 映射不到时 [select] 选项：按标题猜 / 跳过不抓 / 落到其他

## 查重（dedupe，2 个手风琴）

├─ 筛选条件（11 行）
│  ├─ 分辨率要求 [select] 选项：不限 / 1080p 及以上 / 2160p 及以上 说明：抓的时候全抓，发之前按这个卡
│  ├─ 体积范围 [select] 选项：不限 / 5 GB 起 / 10 GB 起 / 20 GB 起
│  ├─ 最大体积 [select] 选项：不限 / 50 GB / 80 GB / 120 GB
│  ├─ 地区版本 [switch] 开关 说明：识别出 US/HKG/TWN 这类版本，写进副标题的地区段
│  ├─ 必须有简介 [switch] 开关 说明：抓不到中文简介就不自动发
│  ├─ 必须带中字 [switch] 开关 说明：成品没有中文字幕就不发
│  ├─ BDInfo [select] 选项：必须存在且校验通过 / 有就行，不校验 / 不要求
│  ├─ 截图至少几张 [text] 默认：3 说明：不够就不自动发
│  ├─ 下载完成再发布 [switch] 开关 说明：种子还没下完就发，容易被删
│  ├─ 种子完整性校验 [switch] 开关 说明：qB 校验通过才算完成
│  └─ 不满足时 [select] 选项：转待确认 / 直接跳过

└─ 已有与归档（5 行）
   ├─ 查本地词库 [switch] 开关 说明：以前查过的结果缓存起来，避免重复请求
   ├─ 词库有效期 [select] 选项：1 天 / 7 天 / 30 天 / 永久
   ├─ 目标站已有原盘 [select] 选项：跳过不收 / 标重复后仍收
   ├─ 目标站只有 DIY [select] 选项：可发（标复核） / 跳过
   └─ 请求失败 [select] 选项：重试 2 次后标失败 / 直接跳过

## 发布（pub，7 个手风琴）

├─ 目标站（6 行）
│  ├─ 发布到 [custom] 说明：所有库内资源都归到这个站
│  ├─ 多目标站 [switch] 开关 说明：同一部片同时发到 2–3 个站，需要各站分类都映射好
│  ├─ 图床 [select] 选项：站内图床（浏览器上传） / 外链图床 API
│  ├─ 截图来源 [select] 选项：从 BDInfo 自动截取 / 抓目标站官方截图 / 手动上传
│  ├─ 目标站分类映射 [button] 默认：配置映射 说明：把目标站分类对到库内分类，发种时据此选分类
│  └─ 发布后校验 [switch] 开关 说明：发完回站里查一遍，确认真的出现并记下种子 ID

├─ 标题与副标题（8 行）
│  ├─ 匹配范围 [select] 选项：标题 / 标题 + 副标题 / 标题 + 简介首段 说明：只读这段文本，不改任何字段
│  ├─ 排除匹配 [custom] 说明：支持正则，限 200 字；只决定转不转，不影响请求
│  ├─ 白名单匹配 [custom] 说明：和排除同时命中时，排除优先
│  ├─ 写错时 [select] 选项：回退成纯文本匹配 / 整条跳过等人工 说明：语法错、超时、超长都走这条
│  ├─ 测试匹配 [custom]
│  ├─ 发布标题 [custom] 说明：标题不做模板，源站怎么写就怎么发
│  ├─ 中文副标题模板 [custom] 说明：用 {电影名} {地区} {导演} {主演1..3} {音轨} {字幕} 这些占位符
│  └─ 副标题语言 [select] 选项：中文 / 中英双语 / 只用英文

├─ 简介（11 行）
│  ├─ 简介图片 [select] 选项：转存到图床 / 保留外链 / 不保留图片 说明：外链会失效，转存最稳
│  ├─ 片名相似度阈值 [text] 默认：0.85 说明：低于这个值不猜，直接转人工
│  ├─ 年份必须一致 [switch] 开关
│  ├─ 匹配来源顺序 [select] 选项：TMDB → 豆瓣 → 站点标题 / 豆瓣 → TMDB → 站点标题 / 只用站点标题
│  ├─ 中文副标题来源 [select] 选项：种子自带 → 豆影网页 → TMDB / 豆影网页 → 豆瓣 → TMDB / 只用种子自带，没有就用英文
│  ├─ 简介来源顺序 [select] 选项：豆影网页 → 豆瓣 → TMDB / 豆瓣 → 豆影网页 → TMDB / 只用 TMDB（zh-CN）
│  ├─ TMDB 接口 [text] 提示：填 API Key 才能自动查导演和主演
│  ├─ 豆影 API Key [text] 提示：免费每天 10 次，用完走网页版
│  ├─ 豆瓣抓取间隔（秒） [text] 默认：3 说明：太快会出验证码
│  ├─ 主演最多几个 [text] 默认：3
│  └─ 缺字段时 [select] 选项：省略该段 / 写「未知」 / 转待确认

├─ 发布字段（6 行）
│  ├─ 制作组 [text] 提示：留空按目标站默认
│  ├─ 来源 [select] 选项：Blu-ray / HDTV / WEB-DL / DVD / 其他
│  ├─ 媒介 [select] 选项：Blu-ray / Encode / Remux / UHD Blu-ray / DVD / 其他
│  ├─ 编码 [select] 选项：AVC / HEVC / VC-1 / MPEG-2 / 其他
│  ├─ 音轨 [text] 提示：留空按源种自动填
│  └─ 字幕类型 [select] 选项：中文字幕 / 中英字幕 / 英文字幕 / 无字幕

├─ 自动发布（6 行）
│  ├─ 自动发布总开关 [switch] 开关 说明：关掉只抓不发，全部留给人
│  ├─ 发布模式 [select] 选项：全自动（过了就直接发） / 半自动（先转待审核） / 仅准备（不碰目标站）
│  ├─ 发布前必须人工点通过 [custom] 选项：必须人工点通过 / 不拦，直接发 说明：点一下选中，和搜索预设里的类型按钮一样
│  ├─ 两条之间间隔（秒） [text] 默认：60 说明：别把目标站刷爆
│  ├─ 每天最多自动发几条 [text] 默认：20
│  └─ 单站每天最多发几条 [text] 默认：10

├─ 失败与兜底（6 行）
│  ├─ 主站已有同片 [select] 选项：转待审核（标重复） / 直接丢弃
│  ├─ 站点标限制分发 [select] 选项：直接丢弃 / 只收录不发布
│  ├─ 图片上传重试 [text] 默认：2 次
│  ├─ 发布失败重试 [text] 默认：2 次，间隔 5 分钟

│  └─ 失败时推送通知 [switch] 开关

└─ 下载条件（4 行）

   ├─ 免费/优惠 [select] 选项：不限制 / 免费优先 / 只要 FREE / FREE 或 2x 说明：免费期再下，省下载量
   ├─ 单站同时下载 [text] 默认：2 说明：同一个站并行任务数，别把站刷爆
   └─ 只在此机器下载 [select] 选项：自动挑磁盘最多的 / 固定 B / 固定 C / 固定 D / 固定 E
