# 流程页规则树（类目 / 手风琴 / 里面的每一条）

由 `pta/web-src/src/data/rules.js` 直接生成：`node pta/scripts/gen-rules-tree.js`。行末的 [类型] 是控件形态，后面是选项或默认值。

## 抓取（fetch，2 个手风琴）

├─ 搜索预设（5 行）
│  ├─ 类型 [custom] 选项：电影 / 剧集 / 综艺 / 动漫 / 纪录片 / 音乐 / 体育 / 演唱会 / MV / 有声书 / 电子书 / 软件 / 游戏 / 短剧 / 舞台演出 / 成人 / 原盘 / Remux / 压制 / 图片 / 样品 / 预告 / 其他 说明：按站映射到分类 id；选中的类型决定抓哪些分类
│  ├─ 媒介 [custom] 选项：原盘(Full Disc) / UHD 原盘 / 3D 原盘 / Remux / Encode / Blu-ray / HDDVD / DVD / HDTV / WEB-DL / WEBRip / TVRip / VHS / 其他 说明：锁到站点的 medium / type 字段
│  ├─ 分辨率 [custom] 选项：480p / 576p / 720p / 1080i / 1080p / 2160p / 4320p/8K 说明：按分辨率筛搜索结果
│  ├─ 优惠 [custom] 选项：免费 / 2x / 2x 免费 / 50% / 2x 50% / 30% / 普通 / 置顶精选 说明：按站点优惠状态筛，BHD 这类站点没有免费选项时会自动跳过
│  └─ 限制 [custom] 选项：禁转 / 限转 / HR / 独占 / DIY 说明：选中即排除；认标题、列表徽章和已抓详情标签

└─ ③ 初筛（6 行）
   ├─ 分辨率要求 [pick] 选项：不限 / 1080p 及以上 / 2160p 及以上 说明：抓的时候全抓，发之前按这个卡
   ├─ 体积范围 [pick] 选项：不限 / 5 GB 起 / 10 GB 起 / 20 GB 起
   ├─ 最大体积 [pick] 选项：不限 / 50 GB / 80 GB / 120 GB
   ├─ 必须带中字 [switch] 开关 说明：成品没有中文字幕就不发
   ├─ 排除匹配 [custom] 说明：支持正则，限 200 字；命中就拒绝，不进待审
   └─ 测试匹配 [custom]

## 查重（dedupe，1 个手风琴）

└─ 查重处理（4 行）
   ├─ 目标站已有原盘 [switch] 开关 说明：开启后目标站已有原盘直接跳过；关闭则不按原盘判重
   ├─ 目标站只有 DIY [switch] 开关 说明：开启后目标站只有 DIY 仍可发布；关闭则跳过
   ├─ 禁转/限转处理 [switch] 开关 说明：开启后源种带禁转/限转直接跳过；关闭则不检查
   └─ 原盘判定关键词 [text] 默认：原盘|Full Disc|BDMV|ISO 说明：标题/副标题/简介/标签都看；Remux/DIY 不算

## 发布（pub，5 个手风琴）

├─ ④ 补齐与准备（5 行）
│  ├─ 标题原样回填 [switch] 开关 说明：开：种子词条标题原样回填；关：标题不齐转待审
│  ├─ 副标题拼贴 [switch] 开关 说明：开：豆影数据拼贴；关：副标题不齐转待审
│  ├─ 简介回填 [switch] 开关 说明：开：豆影简介覆盖电影简介段；关：不联网
│  ├─ 简介图片 [switch] 开关 说明：开：全部转存图床；关：保留源图不转存
│  └─ 自动附加 MediaInfo [switch] 开关 说明：开：自动追加；关：不追加

├─ ⑤ 终审与决策（5 行）
│  ├─ 必须有简介 [switch] 开关 说明：简介不齐转待审
│  ├─ 必须有副标题 [switch] 开关 说明：副标题不齐转待审
│  ├─ BDInfo [switch] 开关 说明：没有 BDInfo/MediaInfo 就转待审
│  ├─ 截图至少几张 [switch] 开关 说明：源简介里的截图必须全部保留
│  └─ 年份必须一致 [switch] 开关 说明：豆影年份最多比种子年份晚 2 年，超过转待审

├─ ⑥ 发布（站点要求）（3 行）
│  ├─ 发布到 [custom] 说明：所有库内资源都归到这个站
│  ├─ 自动勾选标签 [switch] 开关 说明：按来源标签勾国语/中字等；禁转/官方不勾
│  └─ 默认匿名 [switch] 开关 说明：新条目没单独设置时按这个发

├─ ⑦ 发完（5 行）
│  ├─ 发布后校验 [switch] 开关 说明：发布后自动去目标站核对；关掉就只提交不回查
│  ├─ 发布后抓权威种子 [switch] 开关 说明：发布成功抓目标站种子存 data/torrents
│  ├─ 上传前清洗 tracker [switch] 开关 说明：关掉会按源种直传，源站 tracker 会带到目标站
│  ├─ 辅种跳过校验 [switch] 开关 说明：qB skip_checking 复用源种保存路径
│  └─ qB 自动种子管理 [switch] 开关 说明：关掉=autoTMM false，不自动移动文件

└─ ⑧ 失败与通知（2 行）
   ├─ 图片上传重试 [text] 默认：2 次
   └─ 连续失败几次暂停该站 [text] 默认：5
