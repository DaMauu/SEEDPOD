# 流程页规则树（类目 / 手风琴 / 里面的每一条）

由 `pta/web-src/src/data/rules.js` 直接生成：`node pta/scripts/gen-rules-tree.js`。行末的 [类型] 是控件形态，后面是选项或默认值。

## 抓取（fetch，1 个手风琴）

└─ 搜索预设（1 行）
   └─ 优惠 [custom] 选项：免费 / 2x / 2x 免费 / 50% / 2x 50% / 30% / 普通 / 置顶精选 说明：按站点优惠状态筛，BHD 这类站点没有免费选项时会自动跳过 （未接）

## 查重（dedupe，2 个手风琴）

├─ 查重范围（2 行）
│  ├─ 目标站搜索 [switch] 开关 说明：关闭后手动查重不请求目标站
│  └─ 体积容差 [text] 默认：2 说明：体积差在这个百分比内算同一条

└─ 目标站状态（2 行）
   ├─ 目标站已有原盘 [select] 选项：跳过不收 / 标重复后仍收 （未接）
   └─ 目标站只有 DIY [select] 选项：可发（标复核） / 跳过 （未接）

## 发布（pub，5 个手风琴）

├─ 发布条件（16 行）
│  ├─ 发布到 [custom] 说明：所有库内资源都归到这个站
│  ├─ 门槛 [section]
│  ├─ 分辨率要求 [pick] 选项：不限 / 1080p 及以上 / 2160p 及以上 说明：抓的时候全抓，发之前按这个卡
│  ├─ 体积范围 [pick] 选项：不限 / 5 GB 起 / 10 GB 起 / 20 GB 起
│  ├─ 下载完成再发布 [switch] 开关 说明：种子还没下完就发，容易被删 （未接）
│  ├─ 内容要求 [section]
│  ├─ 最大体积 [pick] 选项：不限 / 50 GB / 80 GB / 120 GB
│  ├─ 地区版本 [switch] 开关 说明：识别出 US/HKG/TWN 这类版本，写进副标题的地区段 （未接）
│  ├─ 必须有简介 [switch] 开关 说明：抓不到中文简介就不自动发
│  ├─ 必须带中字 [switch] 开关 说明：成品没有中文字幕就不发
│  ├─ BDInfo [pick] 选项：必须存在且校验通过 / 有就行，不校验 / 不要求
│  ├─ 截图至少几张 [text] 默认：0 说明：0 = 不检查；简介里的截图全部转载
│  ├─ 重复与失败 [section]
│  ├─ 不满足时 [pick] 选项：转待确认 / 直接跳过 说明：上面的条件没达标时怎么处理 （未接）
│  ├─ 图片上传重试 [text] 默认：2 次
│  └─ 连续失败几次暂停该站 [text] 默认：5 （未接）

├─ 标题与副标题（4 行）
│  ├─ 中文副标题来源 [select] 选项：种子自带 → 豆影网页 → TMDB / 豆影网页 → 豆瓣 → TMDB / 只用种子自带，没有就用英文 （未接）
│  ├─ 排除匹配 [custom] 说明：支持正则，限 200 字；只决定转不转，不影响请求
│  ├─ 白名单匹配 [custom] 说明：和排除同时命中时，排除优先
│  └─ 测试匹配 [custom]

├─ 简介（7 行）
│  ├─ 简介图片 [select] 选项：转存到图床 / 保留外链 / 不保留图片 说明：外链会失效，转存最稳
│  ├─ 截图来源 [select] 选项：从 BDInfo 自动截取 / 抓目标站官方截图 / 手动上传 说明：先记录选择，自动截取还没接 （未接）
│  ├─ 片名相似度阈值 [text] 默认：0.85 说明：低于这个值不猜，直接转人工 （未接）
│  ├─ 年份必须一致 [switch] 开关
│  ├─ 匹配来源顺序 [select] 选项：TMDB → 豆瓣 → 站点标题 / 豆瓣 → TMDB → 站点标题 / 只用站点标题 （未接）
│  ├─ 主演最多几个 [text] 默认：3
│  └─ 发布后校验 [switch] 开关 说明：发布后自动去目标站核对；关掉就只提交不回查

├─ 发布字段（1 行）
│  └─ 字幕类型 [pick] 选项：中文字幕 / 中英字幕 / 英文字幕 / 无字幕 （未接）

└─ 下载条件（3 行）
   ├─ 做种数至少 [pick] 选项：不限 / 1 / 3 / 5 / 10 / 20 说明：做种太少的下到一半就断 （未接）
   ├─ 免费/优惠 [pick] 选项：不限制 / 免费优先 / 只要 FREE / FREE 或 2x 说明：免费期再下，省下载量 （未接）
   └─ 单站同时下载 [text] 默认：2 说明：同一个站并行任务数，别把站刷爆 （未接）
