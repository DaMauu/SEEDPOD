# 分类政策（抓取类型）

这份文档说明「流程页 ① 抓取 → 类型」到底怎么生效，以及为什么会出现“选电影却抓到音乐/MV”。

## 1. 事实源

分类有三层，优先级从高到低：

1. 流程页给**当前来源站**选的「类型」；
2. `data/site-search.local.json` 里该站的 `types` / `cats`；
3. 站点包、私有站点定义、`data/site-maps.json` 里的分类 id 与中文标签。

站点分类名先归一到通用类型，再决定抓哪些分类 id。归一规则在 `pta/server/category-policy.js`，抓取和流程页共用同一份。

## 2. 类型归一顺序

顺序有意义，先匹配到的类型生效：

| 类型 | 匹配示例 |
| --- | --- |
| 电影 | 电影、Movie、Film |
| 剧集 | 剧集、电视剧、TV Series、Series |
| 综艺 | 综艺、TV Show、Variety |
| 动漫 | 动漫、动画、Anime、Animation |
| 纪录片 | 纪录、Documentary |
| 演唱会 | 演唱会、Concert |
| MV | MV、音乐短片、Music Video |
| 音乐 | 音乐、Music、音频、Audio |
| 体育 | 体育、Sport |
| 有声书 | 有声书、Audiobook |
| 电子书 | 电子书、Ebook、Book |
| 软件 | 软件、Software、App |
| 学习 | 学习、Study、教育、Tutorial |
| 短剧 | 短剧、Short Drama |
| 舞台演出 | 舞台、Stage |
| 游戏 | 游戏、Game、PlayStation、Xbox、Nintendo |
| 成人 | 成人、Adult、18+ |
| 图片 | 图片、Picture、Image、Photo |
| 样品 | 样品、Sample |
| 预告 | 预告、Trailer |
| 原盘 | 原盘、Full Disc、BDMV |
| Remux | Remux |
| 压制 | 压制、Encode |
| 其他 | 其他、其它、Other、Misc |

`MV` 必须排在 `音乐` 前面，`有声书` 必须排在 `电子书` 前面，否则会被更宽的关键词先吃掉。

## 3. 保存规则

- 「类型」是**按来源站**保存的，不是全局。
- 先在页面上选来源站，再选类型，再点保存。
- 保存时写入该站的 `types` 和 `cats`：
  - `types`：用户选中的类型；
  - `cats`：每个类型匹配到的所有站点分类 id。
- 一个类型可以对应多个分类 id；当前实现会收下所有命中的分类，不再只取第一个。
- 某个类型在本站分类里一个都没匹配到，会提示“这些类型没匹配到本站分类”，不会静默当成全抓。
- 没选来源站就保存类型：不会写文件，并提示“先选来源站”。

## 4. 抓取规则

抓取时按站点读取 `site-search.local.json`：

1. 有 `cats`：只请求这些分类 id；
2. 有 `types`：再用类型硬过滤一次分类；过滤后为空直接报 `NO_CATEGORY_MATCH`，不抓；
3. 没有 `types`：直接报 `NO_CATEGORY_TYPES`，不抓；必须先在流程页按站保存类型，不再回退全分类。

站点适配器的 `catMode` 决定分类参数怎么拼：`single` / `multi` / `bracket` / `indexed`。如果站点忽略分类参数，返回结果仍可能更宽；这时类型硬过滤只能控制“请求了哪些分类”，不能保证站点一定遵守。

## 5. 筛选阶段

初筛（分辨率/体积/中字/排除/查重）**不额外按类型过滤**。类型正确性由抓取分类负责；历史数据如果分类已经是错的，初筛不会自动纠正。

## 6. 为什么会出现“选电影抓到音乐/MV”

历史原因有三个，可能同时存在：

1. 旧版流程页的类型没有按站写入 `types`，只留下一个很宽的分类预设；
2. 抓取只读了 `cats`，没有校验用户选的「电影」；
3. 某站分类预设里 `其他` 组包含音乐/MV 分类 id，抓取就把它们一起抓了。

典型现象：目录里出现大量 `catName=413`（音乐/MV）的词条，而流程页类型显示「电影」。这不是搜索词的问题，是分类预设没有被类型闸门拦住。

## 7. 现在的行为

- 选电影并保存后，该站只会请求电影分类；
- 类型保存会覆盖该站旧的宽预设；
- 没保存类型会提示并停止；没匹配到类型也会停止，不再全抓；
- 类型集合变化会清掉该站 fullDoneAt，下次按全量重跑；只改分类预设仍走增量。
- 历史已经抓错的词条不会自动删除，需要单独清理。

## 8. 操作建议

每个要抓的来源站都执行一次：

1. 选来源站；
2. 选「类型」（例如只选电影）；
3. 点保存，确认没有“没匹配到本站分类”的提示；
4. 再跑抓取。

如果站点分类表本身不可靠，先在「站点映射」里补分类，再保存类型。
