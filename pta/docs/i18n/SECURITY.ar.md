### الإبلاغ عن ثغرة أمنية

يُرجى **عدم** الإبلاغ عن مشكلات الأمان عبر Issue عامة. استخدم القناة الخاصة بالمستودع:

1. افتح تبويب [Security](../../security/advisories) وانقر على "Report a vulnerability";
2. أو تواصل مباشرة مع المشرفين مع خطوات إعادة الإنتاج ونطاق التأثير.

نهدف إلى الرد خلال 7 أيام، وبعد التأكيد نتفق معك على الإصلاح وتوقيت الكشف.

### ما الذي يجب الإبلاغ عنه

تعمل userscript الخاصة بـ SEEDPOD على صفحات tracker خاصة مسجّل الدخول إليها، ويمكنها قراءة محتوى الصفحة وإرسال طلبات نيابة عنك. كل ما يلي يُعد مشكلة أمان:

- إرسال بيانات الاعتماد (cookie وpasskey ومفاتيح tracker وكلمات مرور الحساب) إلى عنوان طرف ثالث
- طلبات صادرة غير موثّقة (إلى نطاقات غير مضيف الصور أو CDN أو الخدمات التي تصفها الوثائق)
- مسارات XSS تحقن محتوى يتحكم به المهاجم في اللوحة أو مربعات الحوار
- حقن صلاحيات أو معاملات في فحص التكرار بين المواقع أو تعبئة نموذج الرفع أو الدفع إلى downloader
- أوراق أنماط تحمّل موارد غير موثوقة عبر `@import` خارجي

### خارج النطاق

- الثغرات في الـ tracker نفسه (أبلغ الموقع المعني بها)
- قواعد الموقع أو محتوى torrent أو حظر الحسابات
- المشكلات التي تتطلب وصولًا مسبقًا إلى ملفاتك المحلية أو سياق إضافة المتصفح

### عند تقديم Issue أو PR

قبل نشر السجلات أو لقطات الشاشة، احذف: cookie وpasskey ومفاتيح tracker وعناوين downloader وكلمات مروره وأسماء المستخدمين في الموقع. أبقِ stack trace، ولا تلصق ترويسات الطلب كاملة.
