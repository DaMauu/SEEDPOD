شكرًا لرغبتك في تحسين SEEDPOD. اقرأ هذه الصفحة أولًا — فهذا يوفّر معظم المراسلات ذهابًا وإيابًا.

### ما هذا المستودع

إضافات من ملف واحد: سكربتات المستخدم Tampermonkey وأوراق الأنماط الخارجية. **لا بناء، ولا اعتماديات، ولا خادم خلفي** — ضع ملفًا واحدًا وسيعمل. لا تُدخل أدوات تجميع أو اعتماديات npm أو خطوات تصريف في طلب الدمج.

### البنية

| المسار | المحتوى |
|---|---|
| `scripts/bluray/legacy/` | إصدارات لوحة bluray المنشورة، ملف واحد لكل إصدار |
| `scripts/bluray/docs/` | البدء السريع، الدليل، البنية المعمارية، ملاحظات التطوير |
| `scripts/PTScripts/` | مجموعة أدوات مساعدة للمتتبعات، تتبع upstream `DaMauu/Scripts` |
| `styles/r/` | أنماط سمات المتتبعات |
| `pta/` | صفحة ملاحظات البنية المعمارية للمتتبعات محليًا |

### الإصدارات

- **bluray**: اسم الملف `pt-bluray-assistant-v0.0.0.N.user.js`، أربعة مقاطع تتزايد. **لا تستبدل إصدارًا قديمًا ولا تحذفه أبدًا** — أضف ملفًا جديدًا. يجب أن تتطابق ترويسة `@version` وعنوان اللوحة وسطر السجل عند الحقن.
- **styles**: ملف واحد لكل نمط، عند التعديل ارفع الإصدار وأضف tag؛ تبقى tag القديمة إلى الأبد ليتمكن المستخدمون من الرجوع.
- **PTScripts**: يضمن هذا المستودع فقط بقاء الملفات متاحة على الإنترنت؛ مصدر الحقيقة هو upstream `DaMauu/Scripts`. أرسل التغييرات إلى upstream أولًا ثم زامنها عائدة.

### قبل الإرسال

1. يُثبَّت السكربت في Tampermonkey ويعمل فعلًا على الموقع المستهدف — لا «يُفترض أن يعمل».
2. اذكر أنواع المتتبعات التي تحققت عليها (NexusPHP / UNIT3D / Gazelle / f3nix)؛ أسماء المواقع مفيدة.
3. أزل `console.log` الخاصة بالتنقيح والمسارات المحلية وحسابات الاختبار.
4. لا تُودِع بيانات المتتبعات المحلية: `pta/web/assets/sites-data.local.js` و`pta/data/site-arch.local.csv` موجودة في `.gitignore` — لا تفرض إضافتها بـ`git add -f`.
5. **لا تُودِع أبدًا** أي cookie أو passkey أو مفاتيح متتبعات أو مفاتيح API أو لقطات شاشة تحوي بيانات شخصية.

### رسائل commit

وصف موجز لما تغيّر وأي وحدة يتأثر، مثل:

```
bluray: 修复 UNIT3D 站点填单时海报字段丢失
styles/r: 调深列表分隔线
```

الصينية أو الإنجليزية، كلتاهما مقبولة.

### طلبات الدمج

- طلب دمج واحد لكل أمر؛ أبقِ تغييرات التنسيق غير المتعلقة خارجًا.
- اشرح: الدافع، الوحدات المتأثرة، طريقة التحقق والنتيجة، وهل تُمس ملفات الإصدارات القديمة.
- أرفق لقطات شاشة لتغييرات اللوحة أو الأنماط — مع حجب الحسابات والمفاتيح.

### Issues

أبلغ عن الأخطاء والطلبات عبر القوالب. لا تفتح Issue عامة لمشاكل الأمان — راجع [SECURITY.md](../../SECURITY.md).
