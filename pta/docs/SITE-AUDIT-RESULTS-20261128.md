# 站点识别体检结果（2026-11-28）

范围：306 个站，每站最多 2 次 GET（搜索页 1 次、上传页 1 次），不重试、不提交上传、不写站点配置。

## 总览

- 有 cookie：204 个；无 cookie：102 个。
- 实际请求：404 次。
- 结果：完全正常 1 个；部分可用 106 个；登录失效 46 个；无 cookie 102 个；403/限流 8 个；其他错误 43 个。
- 上传表单：86 个站有表单；75 个识别到分类控件；只有 1 个是复选/单选组；15 个有多个分类字段。
- 没有上传表单：25 个；有表单但没有分类控件：11 个。
- 旧发布映射重复：22 个站；新旧发布映射不同：80 个站。

## 共性别名候选

这些标签在多个站重复出现，适合先做统一处理，不要逐站改：

- `medium`：CD（32 站）、Track（13）、Media（7）、SACD（7）、Soundboard（5）、DAT（5）、Vinyl（4）、Cassette（3）。
- `resolution`：Other（15）、2K（3）。
- `discount`：Leech Status（5）、Neutral Leech（5）、Either（4）——这些更像页面说明文字，不应硬映射成优惠。
- `type`：Release type、Unknown、EP、Compilation、Interview、Album、Single、Live album、KB/MB/GB/TB——这些是音乐 release type 或容量单位，不是内容分类；当前被当成分类是误判。

## 判断

- 大头不是解析器坏了，是 cookie、登录和路径问题：148 个站缺凭据/登录失效，76 个站路径 404。
- 搜索未识别里，`medium:CD` 等音乐媒介和 `type:Release type` 等 release type 是共性误判，应该先统一处理，能一次消掉很多噪声。
- 上传表单只有 86 个有；其余多为权限/未开放，不能靠改代码补出来。
- 多分类字段、题材字段、无分类控件属于单站差异，不能批量写。
- 发布映射重复 22 个，重识别后可按“一个 option 只落一个类型”修；新旧映射不同的 80 个必须先预览再写。

## 建议顺序

1. 先修共性误判：音乐 release type 不再当内容分类；CD/SACD/Vinyl 等音乐媒介补别名或单列；`Other/2K` 等分辨率别名。
2. 再修路径：Gazelle/Unit3D 的搜索页、上传页默认路径，按引擎补默认值；仍 404 的单站改。
3. 处理凭据：102 个无 cookie、46 个登录失效，先重新导入；不要拿解析器背锅。
4. 上传表单：25 个无表单先确认权限；86 个有表单的逐站预览，再写 `publish.upload`。
5. 最后处理单站差异：15 个多分类字段、4 个题材字段、11 个无分类控件。

原始页面和每站明细在本地数据目录 `site-audit/`，含 cookie 风险，不复制到仓库。
